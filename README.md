# Happy Birthday Card

An interactive and animated **Happy Birthday Card** built using **HTML, CSS, and JavaScript**.

This project is a creative frontend project designed to create a digital birthday greeting with an interactive card, birthday message, cake and candle decorations, and animated fireworks.

---

## 🎂 About The Project

The **Happy Birthday Card** is a simple interactive web-based birthday greeting.

The project features a large **Happy Birthday** heading along with an interactive birthday card. The card uses CSS 3D transformations and animations to create a card-opening effect when the user interacts with it.

Inside the card, a personalized birthday message is displayed along with a sender name.

The project also includes a JavaScript-based fireworks animation that creates animated fireworks on the screen and responds to user clicks and touch interactions. :contentReference[oaicite:2]{index=2} :contentReference[oaicite:3]{index=3}

## 🎨 Card Animation

The birthday card uses a 3D-style interaction.

When the user hovers over the card:

- The card slightly rotates.
- A shadow effect is applied.
- The front cover rotates away.
- The front text is hidden.
- Decorative elements are hidden.
- The inside birthday message becomes visible.

The card uses CSS `perspective` and `rotateY` transformations to create this effect. :contentReference[oaicite:6]{index=6}
